# Desafio Engenharia de Software — Baita Feira 2026

Experiência interativa para o estande de Engenharia de Software da UNIPAMPA.

## Como abrir
1. Extraia a pasta.
2. Abra `index.html` no Chrome/Edge/Firefox.
3. Pode rodar sem servidor e sem backend.

## Conteúdo
- Desafio 1: Caça ao Bug / segurança de interface
- Desafio 2: validação de resposta de IA
- Desafio 3: quiz de áreas de Engenharia de Software
- Resultado + QR Code para conhecer o curso

## Para usar em tela cheia
No Chrome, pressione `F11`.

## Observação sobre marcas
Os símbolos do cabeçalho foram reconstruídos em SVG/CSS para o protótipo funcionar sem internet. Se você tiver os arquivos oficiais em PNG/SVG da Baita Feira, UNIPAMPA e Engenharia de Software, eles podem ser substituídos facilmente no cabeçalho.
